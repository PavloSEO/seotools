- Add `scan-fragment-links` (`seo_scan_fragment_links`) and the
  `BROKEN_BOOKMARK` audit check: every fragment-bearing `<a href>` in retained
  complete HTML/DOM is resolved against the destination document's element ids
  and `<a name>` targets using the WHATWG scroll-to-the-fragment algorithm
  (the serialized fragment is tried against ids and names first, then the
  percent- and UTF-8-decoded value against both; `+` stays a literal plus;
  `#` and `#top` resolve to the document top). Static, rendered,
  and legacy-fragment representations are evaluated independently, redirect
  and `<base href>` rules are honored, and a different query string is a
  different document. Missing, truncated, unsupported, failed, or
  budget-exhausted bodies are reported as named skips -- never as broken
  findings -- and Screaming Frog exports and legacy imports name the check
  unavailable rather than claiming it ran clean. Results are bounded and
  deterministically paginated (`total`, `returned`, `offset`/`limit`,
  `next_offset`, coverage state), identical through the CLI, MCP, and the
  retained-scan audit summary. Nothing is fetched: the evaluation is
  read-only and offline.
