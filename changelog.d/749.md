- Native URL crawls can filter discovered routes by final filename extension before requests and by actual response `Content-Type` before parsing or body retention. Both filter stages record their decisions while preserving link, status, header and redirect evidence; filtered HTML metadata remains explicitly unmeasured. Script/stylesheet resources keep their independent selection and byte budgets.
- When an HTML body is unavailable, body-derived findings now retain explicit skipped coverage instead of treating parser defaults as clean or as observed missing metadata.
